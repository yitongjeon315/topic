# TOPIK 실시간 번역 수업방

Google Apps Script의 무료 `LanguageApp` 번역 기능을 사용하는 교사·학생용 웹앱입니다.

## 기능

- 교사가 입력한 한국어를 영어, 중국어 간체, 베트남어, 네팔어로 번역
- 1.2초 입력 중지 후 자동 번역 또는 수동 번역
- 학생별 번역 언어 선택
- 1.5초 간격으로 최신 판서 확인
- 교사 비밀번호와 수업방 쓰기 키로 판서 변경 제한
- 수업방은 마지막 입력 후 8시간 동안 유지

## 배포 설정

1. Apps Script 프로젝트를 만들고 `Code.gs`, `Index.html`, `appsscript.json`을 추가합니다.
2. 웹앱으로 배포합니다.
3. 실행 계정은 본인, 액세스 권한은 `모든 사용자`로 설정합니다.
4. 최초 접속 시 교사 비밀번호를 설정합니다.
5. 새 수업방을 만들고 학생 링크를 공유합니다.

개인 Google 계정은 Apps Script 번역 호출을 하루 5,000회까지 사용할 수 있습니다. 한 문장을 4개 언어로 번역하므로 입력 한 번에 번역 호출 4회를 사용합니다.
